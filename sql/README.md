# SQL Demos

This folder contains beginner-friendly SQL examples using:

## 🏥 Health Data
Demonstrates:
- Filtering patients by age
- Joining patient visits
- Calculating bills + tax
- Grouping by patient

## 🏀 Sports Data
Demonstrates:
- Filtering by team
- Player-game performance joins
- Creating a 'total contribution' column
- Grouping player averages
